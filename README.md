## 适合谁使用

**主播与角色创作者使用 FurryUP Studio。** 在这里准备直播、管理互动、查看助手建议，并向粉丝分享已授权的角色模型。

**粉丝使用独立的 FurryUP 桌宠。** 接收主播分享，在自己的桌面上使用喜欢的角色。两端分别安装、分别更新。

## 可以做什么

| 功能 | 使用方式 |
| --- | --- |
| **开播准备** | 保存平台与出镜方式，检查并启动 OBS Studio、平台直播工具等本机软件，减少开播前的重复操作。 |
| **直播工作台** | 集中查看哔哩哔哩、抖音、快手和视频号的连接状态与互动消息，将弹幕与互动画面接入 OBS Studio。 |
| **声音与现场控制** | 使用弹幕朗读、欢迎与礼物感谢、音效台和点歌队列，调整声音、暂停或跳过播放。 |
| **直播助手** | 查看互动提醒、话题建议、礼物节目安排、投票和本场复盘；由主播决定是否采纳与执行。 |
| **桌宠联动** | 管理角色与 Live2D 模型，为同一角色添加、选择和独立命名多款模型，明确发布后分享给粉丝。 |
| **账户与插件** | 使用邮箱验证码登录或绑定账户，通过插件中心管理安装、运行、停用、更新、回滚和卸载。 |

### 直播准备与互动

FurryUP Studio 将常用工具的启动和平台互动放进同一个工作区。完成房间和登录配置后，可在直播工作台查看消息，并配置 OBS Studio 中的弹幕样式、背景板和相关互动。

各平台提供的消息种类、字段和投递情况不同，实际能力以客户端连接状态为准。外部直播软件需事先安装和配置；正式开播前，仍需主播确认画面、模型、音频与推流设置。当前不承诺自动完成四平台正式开播或一键关播。

联网语音需要网络连接，在线点歌需要配置兼容的音乐服务。

### 让助手帮忙整理，保留主播自己的节奏

直播助手提供实时建议与复盘入口。建议先展示给主播；问题和投票需由主播明确采纳或开始后才进入 OBS Studio。在线建议需要主动发起，并使用本机已登录 Codex 账户的可用额度。

助手可独立启停和更新。停止助手不会中断直播工作台的消息采集，原有记录继续保留。

### 把角色陪伴延续到直播之外

通过桌宠联动管理角色和模型，准备好后再明确发布或同步给粉丝。同一角色可管理多款模型，粉丝通过分享链接确认下载，并在粉丝端自行选择。

启动软件或恢复会话不会自动发布本机模型。公开分享前需要连接账户，并确认拥有模型及相关素材的分发权限。

## 本次更新 · 0.6.0-beta.14

- **邮箱账户入口：** 支持验证码登录、注册与邮箱绑定；已有本机账户绑定邮箱时，保留原账户的权益与创作者记录。
- **自愿赞赏：** 支持微信、支付宝收款码切换和放大查看；金额自行填写，不用于购买套餐或解锁功能，也不会开启自动续费。
- **新版插件：** 整合直播工作台、直播助手和桌宠联动的更新，继续支持兼容范围内的独立更新。
- **公开发行范围：** 本包不包含 iPhone 投屏插件及内部接收器；该功能仍处于内部 Alpha 阶段。
